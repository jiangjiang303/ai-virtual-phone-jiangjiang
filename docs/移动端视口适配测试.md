# 移动端视口适配测试分支

> **仅用于适配测试，不是正式分享版更新。** 正式稳定版本仍为 `main`。
> 如果原版显示正常，请继续使用 `main`，不需要切换。

## 本分支调整

- **Android Chrome / Edge / APK WebView：** 移动端铺满屏幕不再依赖 `hover:none` 和 `pointer:coarse` 同时成立，减少部分 WebView 误判为桌面模型、露出手机外壳和向右下偏移的问题。
- **iPhone Safari / 添加到主屏幕：** 手机容器改为按动态视口高度计算，并为底部 Dock 预留系统安全区，以降低顶部留白和 Dock 裁切风险。
- **保留大屏展示：** 宽屏浏览器继续显示原来的虚拟金属手机外壳。
- 这次仅调整外壳布局 CSS，不更改 Chat、LYSN、音乐、AI 或任何业务功能。

## 怎么部署测试

1. 打开仓库的 `test/viewport-compat` 分支，而不是 `main`。
2. 在支持 Git 分支部署的平台（例如 Vercel）选择该分支创建独立部署；已连接的项目可查看此分支的 Preview Deployment。**不要把正式 Production Branch 改成测试分支。**
3. iPhone Safari 先打开测试网址检查布局；需要测“添加到主屏幕”时，测试网址须是可访问的 HTTPS 地址。
4. 要测试 APK：从本分支源码构建 APK，在实际出现错位的 Android 设备上验证。只看网页部署结果不能代替 APK 测试。

## 希望反馈的信息

- 设备型号、Android/iOS 版本，以及使用 Chrome、Edge、Safari、添加到主屏幕或 APK 中的哪一种。
- **桌面首屏截图**（应显示完整桌面、顶部状态栏和底部 Dock）。
- 问题发生在浏览器还是 APK；若 APK 有错位，提供同设备部署网页版与 APK 的对比截图。
- 是否开启系统显示放大、文字放大或自定义外观 CSS。
- 是否仍有顶部白条、Dock 不全、页面右下偏移；键盘弹出后是否产生新的错位。

**当前这是候选修复，尚未经过用户设备实测；不同设备是否适配仍以测试反馈为准。**
